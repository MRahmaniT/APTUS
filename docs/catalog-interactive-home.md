# Catalog cover and interactive homepage

The homepage keeps the website navigation, account/CMS functions, product routes, news, projects and protected library. The cover now uses the catalog's exact title markup, emphasis, AIPS-FFP English brand line, vignette and responsive image effects. A short About APTUS block precedes the catalog's original selectable assembly diagram, eight numbered pins and nine component controls. The detail dock animates on selection and links to the existing product pages. The AIPS introduction uses the catalog's exact paragraphs and stacked render/CAD images.

The five-image website accordion again uses GSAP for expansion, tilt and parallax, with the catalog application photos and labels. On touch screens it stacks vertically and selects a collapsed image on the first tap. Reduced-motion preferences disable tweening and preview entry effects.

The catalog stylesheet cascade is scoped to the homepage so it does not alter account, CMS or other website pages. Source: APTUS-Catalog 75c645424c5ac5dba0d27c15e889d07a1aeebf91. All media is bundled locally.

Validation: production build, type checking, source asset hashes, account/CMS smoke tests, exact catalog text/style comparisons, all component selections and numbered pins, GSAP expansion/keyboard/hover, multilingual responsive pages and protected library.
